# Contracts

Versioned, language-neutral contracts live here. Runtime packages consume these contracts; they do not redefine their semantics.

- `openapi/` — public management and Process API descriptions
- `workflow/` — the canonical visual, YAML, JSON, and runtime workflow schema
- `events/` — versioned event envelopes and payload schemas
- `connectors/` — connector protocol and capability schemas

The directories are established as ownership boundaries. Product schemas arrive with the capability workorders that define them.
