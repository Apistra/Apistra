# Security Policy

## Supported versions

Apistra is pre-release software. Only the latest published 0.x version or the current `main` commit is considered for security fixes.

## Reporting a vulnerability

Use the repository's private **Security → Report a vulnerability** function. Do not open a public issue and do not include credentials or customer data.

Include the affected commit or version, deployment mode, reproduction steps, impact, and any safe supporting evidence. Maintainers will acknowledge a valid channel report, coordinate validation and remediation, and publish an advisory when disclosure is safe. No response-time guarantee is made during the research phase.

## Scope boundaries

Only systems and data you own or are explicitly authorised to test are in scope. Denial of service, social engineering, credential attacks, and access to third-party data are prohibited.
