## Objective

Prove that Read, Write, and Administrative effects are explicit and that Write
or Administrative actions require approval unless an exact active policy
exception matches project, tool version, action, and scope.

## Preconditions

- The unchanged CAP-02 staging candidate is identified by `CAPABILITY_CANDIDATE_SHA`.
- `FX-PRC-01-CAP02-POLICIES` is applied with the three declared tool effects.
- The fixture receipt resolves the authorised local `CAP02_POLICY_PROBE` without
  granting production or external side-effect access.
- A fresh browser profile resolves `STAGING_SIGN_IN_URL` and protected parameter
  `STAGING_ADMIN_PASSWORD`.

## Procedure

1. **Action (Logged-out visitor):** Open `STAGING_SIGN_IN_URL` in the fresh browser profile.
   **Test data:** `STAGING_SIGN_IN_URL`
   **Expected result:** The page title is `Sign in`.
2. **Action (Logged-out visitor):** Enter the Administrator username in `Username`.
   **Test data:** `admin.alpha`
   **Expected result:** `Username` contains exactly `admin.alpha`.
3. **Action (Logged-out visitor):** Enter the protected password in `Password`.
   **Test data:** protected parameter `STAGING_ADMIN_PASSWORD`
   **Expected result:** `Password` displays only masked characters.
4. **Action (Logged-out visitor):** Select `Sign in`.
   **Test data:** visible action `Sign in`
   **Expected result:** The page title is `Project overview`.
5. **Action (Administrator):** Select project `Atlas Research`.
   **Test data:** project key `ATLAS`
   **Expected result:** `Atlas Research` is displayed as the current project.
6. **Action (Administrator):** Select navigation item `Tools`.
   **Test data:** visible navigation label `Tools`
   **Expected result:** The page title is `Tools`.
7. **Action (Administrator):** Open tool version `research-readonly@2`.
   **Test data:** tool `research-readonly@2`
   **Expected result:** `Effect class` displays `Read` without the default-approval warning.
8. **Action (Administrator):** Open tool version `document-write@1`.
   **Test data:** tool `document-write@1`
   **Expected result:** `Effect class` displays `Write` and `Approval required by default`.
9. **Action (Administrator):** Open tool version `connector-admin@1`.
   **Test data:** tool `connector-admin@1`
   **Expected result:** `Effect class` displays `Administrative` and `Approval required by default`.
10. **Action (Administrator):** Submit the prepared Read decision through the authorised local policy probe.
    **Test data:** `CAP02_POLICY_PROBE` case `read-default`
    **Expected result:** The decision is `ALLOW` without an approval request.
11. **Action (Administrator):** Submit the prepared Write decision without an exception.
    **Test data:** `CAP02_POLICY_PROBE` case `write-default`
    **Expected result:** The decision is `REQUIRE_APPROVAL` and no write occurs.
12. **Action (Administrator):** Submit the prepared Write decision with the exact active exception.
    **Test data:** `CAP02_POLICY_PROBE` case `write-exact-exception`
    **Expected result:** The decision is `ALLOW` for only the named project, tool version, action, and scope.
13. **Action (Administrator):** Submit the prepared Write decision with an expired exception.
    **Test data:** `CAP02_POLICY_PROBE` case `write-expired-exception`
    **Expected result:** The decision is `REQUIRE_APPROVAL` and no write occurs.
14. **Action (Administrator):** Submit the prepared Write decision with a timed-out policy evaluation.
    **Test data:** `CAP02_POLICY_PROBE` case `write-timeout`
    **Expected result:** The decision is `DENY` and no write or approval grant occurs.
