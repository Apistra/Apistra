## Objective

Prove that foreign-project, revoked, tampered, and unresolved secret references
are rejected without revealing whether a protected secret exists.

## Preconditions

- The unchanged CAP-02 staging candidate is identified by `CAPABILITY_CANDIDATE_SHA`.
- `FX-PRC-01-CAP02-CATALOG` is applied with Atlas authorised and Orion foreign.
- The fixture receipt resolves `CAP02_INVALID_REFERENCE_ENDPOINT_URLS` for the
  foreign, revoked, tampered, and unresolved variants without exposing values.
- A fresh browser profile can resolve `STAGING_SIGN_IN_URL` and the protected
  parameter `STAGING_ADMIN_PASSWORD`.

## Procedure

1. **Action (Logged-out visitor):** Open `STAGING_SIGN_IN_URL` in the fresh browser profile.
   **Test data:** `STAGING_SIGN_IN_URL`
   **Expected result:** The page title is `Sign in`.
2. **Action (Logged-out visitor):** Enter the Administrator username in `Username`.
   **Test data:** `admin.alpha`
   **Expected result:** `Username` contains exactly `admin.alpha`.
3. **Action (Logged-out visitor):** Enter the protected password in `Password`.
   **Test data:** protected parameter `STAGING_ADMIN_PASSWORD`
   **Expected result:** `Password` displays only masked characters.
4. **Action (Logged-out visitor):** Select `Sign in`.
   **Test data:** visible action `Sign in`
   **Expected result:** The page title is `Project overview`.
5. **Action (Administrator):** Select project `Atlas Research`.
   **Test data:** project key `ATLAS`
   **Expected result:** `Atlas Research` is displayed as the current project.
6. **Action (Administrator):** Select navigation item `Model Endpoints`.
   **Test data:** visible navigation label `Model Endpoints`
   **Expected result:** The page title is `Model endpoints`.
7. **Action (Administrator):** Open the fixture-prepared foreign-reference endpoint draft.
   **Test data:** resolved `CAP02_INVALID_REFERENCE_ENDPOINT_URLS.foreign`
   **Expected result:** The form displays `Secret reference is unavailable.` without the Orion secret name or identifier.
8. **Action (Administrator):** Open the fixture-prepared revoked-reference endpoint draft.
   **Test data:** resolved `CAP02_INVALID_REFERENCE_ENDPOINT_URLS.revoked`
   **Expected result:** The form displays `Secret reference is unavailable.` without previous status or version metadata.
9. **Action (Administrator):** Open the fixture-prepared tampered-envelope endpoint draft.
   **Test data:** resolved `CAP02_INVALID_REFERENCE_ENDPOINT_URLS.tampered`
   **Expected result:** The form displays `Secret reference is unavailable.` without cryptographic diagnostics or value fragments.
10. **Action (Administrator):** Open the fixture-prepared unresolved-reference endpoint draft.
    **Test data:** resolved `CAP02_INVALID_REFERENCE_ENDPOINT_URLS.unresolved`
    **Expected result:** The form displays `Secret reference is unavailable.` with the same visible wording as steps 7 through 9.
11. **Observation (Administrator):** Inspect the current project secret selector.
    **Test data:** foreign secret name `foreign-provider`
    **Expected result:** No Orion secret name, identifier, count, or version is visible.
12. **Action (Administrator):** Open the foreign project secrets route.
    **Test data:** resolved `ORION_SECRETS_URL`
    **Expected result:** The project-not-found/permission state appears without Orion secret metadata.

## Cleanup

Restore the named fixture snapshot through the authorised CAP-02 reset command
and retain its reset receipt. Do not attempt to repair fixture envelopes manually.

## Required evidence and oracle

- screenshots of steps 7 through 12 with no secret values or foreign metadata;
- safe audit identifiers for each denied variant and the foreign route attempt;
- candidate SHA, fixture checksum, environment, tester, UTC times, and attempt;
- pass only if every variant is denied with indistinguishable safe disclosure.
