## Objective

Prove that an authenticated Administrator cannot discover or render an existing
project outside the Administrator's authorised project set and that the denial
is indistinguishable from an unknown project.

## Preconditions

- The isolated local staging candidate is identified by
  `CAPABILITY_CANDIDATE_SHA`.
- `FX-PRC-01-ISOLATION` is prepared and verified.
- The browser has a fresh profile with no Apistra cookies or storage.
- `STAGING_ADMIN_PASSWORD`, `STAGING_SIGN_IN_URL`, and
  `STAGING_PROJECT_URL_TEMPLATE` are available.

## Procedure

1. **Action (Logged-out visitor):** Open `STAGING_SIGN_IN_URL` in the fresh browser profile.
   **Test data:** `STAGING_SIGN_IN_URL`
   **Expected result:** DSN-001 has page title `Sign in`.
2. **Action (Logged-out visitor):** Enter the fixture username in `Username`.
   **Test data:** `admin.alpha`
   **Expected result:** `Username` contains exactly `admin.alpha`.
3. **Action (Logged-out visitor):** Enter the protected password in `Password`.
   **Test data:** protected parameter `STAGING_ADMIN_PASSWORD`
   **Expected result:** `Password` displays only masked characters.
4. **Action (Logged-out visitor):** Select `Sign in` once.
   **Test data:** visible action `Sign in`
   **Expected result:** DSN-003 has page title `Project overview` and `Current project` is `Atlas Research`.
5. **Action (Administrator):** Open `Current project`.
   **Test data:** accessible name `Current project`
   **Expected result:** The selector lists `Atlas Research` and does not list `Orion Restricted`.
6. **Action (Administrator):** Navigate directly to the foreign project URL.
   **Test data:** project ID `22222222-2222-4222-8222-222222222222`
   **Expected result:** The page title is `Project not found`.
7. **Observation (Administrator):** Inspect the denial message.
   **Test data:** body text region
   **Expected result:** The body reads `The project does not exist or you do not have access.`.
8. **Observation (Administrator):** Inspect the rendered denial page for fixture metadata.
   **Test data:** foreign values `Orion Restricted` and `22222222-2222-4222-8222-222222222222`
   **Expected result:** Neither foreign value is rendered in page content, title, breadcrumbs, navigation, alerts, or accessible names.
9. **Action (Administrator):** Navigate directly to an unknown project URL.
   **Test data:** project ID `99999999-9999-4999-8999-999999999999`
   **Expected result:** The page title is `Project not found`.
10. **Observation (Administrator):** Compare the unknown-project message with step 7.
    **Test data:** expected body text `The project does not exist or you do not have access.`
    **Expected result:** The visible title and body text are identical to the foreign-project response.

## Cleanup

Sign out, close the browser profile, restore `FX-PRC-01-ISOLATION`, and record
the fixture reset receipt.

## Required evidence and oracle

- screenshots of steps 5, 7, and 10; URL-bar evidence may contain only the
  synthetic fixture IDs defined by this case;
- candidate/environment/fixture identities, browser/version, tester, UTC
  start/end, and attempt;
- pass only if the foreign project is absent from selection, no foreign metadata
  is rendered, and the foreign/unknown visible responses are identical.
