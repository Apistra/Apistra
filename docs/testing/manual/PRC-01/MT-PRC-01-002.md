## Objective

Prove that completed bootstrap is enforced server-side and that neither the
sign-in page nor a direct stale bootstrap URL exposes a second creation form.

## Preconditions

- The isolated local staging candidate is identified by
  `CAPABILITY_CANDIDATE_SHA`.
- `FX-PRC-01-ADMIN-NO-PROJECT` is prepared and verified.
- The browser has a fresh profile with no Apistra cookies or storage.
- `STAGING_ADMIN_PASSWORD`, `STAGING_SIGN_IN_URL`, and
  `STAGING_BOOTSTRAP_URL` are available as protected/environment parameters.

## Procedure

1. **Action (Logged-out visitor):** Open `STAGING_SIGN_IN_URL` in the fresh browser profile.
   **Test data:** `STAGING_SIGN_IN_URL`
   **Expected result:** DSN-001 has page title `Sign in` and does not render `Create Administrator`.
2. **Action (Logged-out visitor):** Enter the fixture username in `Username`.
   **Test data:** `admin.alpha`
   **Expected result:** `Username` contains exactly `admin.alpha`.
3. **Action (Logged-out visitor):** Enter the protected password in `Password`.
   **Test data:** protected parameter `STAGING_ADMIN_PASSWORD`
   **Expected result:** `Password` displays only masked characters.
4. **Action (Logged-out visitor):** Select `Sign in` once.
   **Test data:** visible action `Sign in`
   **Expected result:** DSN-003 has page title `Project overview` and `Administrator menu` is available.
5. **Action (Administrator):** Open `Administrator menu`.
   **Test data:** accessible name `Administrator menu`
   **Expected result:** The menu renders `Installation status` and `Sign out`.
6. **Action (Administrator):** Select `Installation status`.
   **Test data:** visible action `Installation status`
   **Expected result:** The view renders `Administrator bootstrap is complete.` and no bootstrap creation form.
7. **Action (Administrator):** Navigate directly to the stale bootstrap URL.
   **Test data:** `STAGING_BOOTSTRAP_URL`
   **Expected result:** The view still renders `Administrator bootstrap is complete.` and no `Password`, `Confirm password`, or `Create Administrator` control.
8. **Action (Administrator):** Select `Audit`.
   **Test data:** navigation item `Audit`
   **Expected result:** DSN-020 has page title `Audit log`.
9. **Observation (Administrator):** Count bootstrap-completed events for the fixture installation.
   **Test data:** event label `administrator.bootstrap.completed`
   **Expected result:** Exactly one matching event exists; the direct route visit created no second Administrator and no second completion event.

## Cleanup

Restore `FX-PRC-01-ADMIN-NO-PROJECT` and record the fixture reset receipt.

## Required evidence and oracle

- screenshot of steps 1, 7, and 9 with no credential or session material;
- candidate/environment/fixture identities, browser/version, tester, UTC
  start/end, and attempt;
- pass only if the form is absent at both entry points and the bootstrap event
  count remains exactly one.
